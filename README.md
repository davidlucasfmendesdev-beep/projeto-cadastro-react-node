## 🚀 Sobre o Projeto
Este projeto foi desenvolvido como parte do meu aprimoramento prático em Análise e Desenvolvimento de Sistemas. O objetivo principal foi ir além do básico e criar uma ponte real entre uma interface interativa no navegador e um banco de dados em nuvem, lidando com requisições HTTP, configuração de rotas e persistência de dados.

## 🛠️ Tecnologias Utilizadas

**Frontend:**
* React.js (com Vite)
* JavaScript / HTML5 / CSS3
* Axios (Consumo de API)

**Backend:**
* Node.js + Express
* Prisma ORM
* MongoDB (Banco de Dados NoSQL na nuvem)

## ⚙️ Como executar localmente (Para Desenvolvedores)

*A maioria dos visitantes pode apenas testar o projeto no link no topo da página, mas deixo esta documentação para fins de avaliação técnica e colaboração.*

Para rodar este projeto na sua máquina, você precisará ter o [Node.js](https://nodejs.org/) instalado.

1. Clone o repositório:
--bash
git clone [https://github.com/davidlucasfmendesdev-beep/projeto-cadastro-react-node.git](https://github.com/davidlucasfmendesdev-beep/projeto-cadastro-react-node.git)

Instale as dependências do Frontend e inicie:

Bash
cd cadastro-usuarios
npm install
npm run dev
Em outro terminal, instale as dependências da API e inicie o servidor:

Bash
cd API
npm install
node --watch server.js
(Obs: É necessário configurar um arquivo .env com a sua própria string de conexão do MongoDB para o backend funcionar).
